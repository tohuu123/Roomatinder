## 📡 Area Radar Feature

The app now includes a powerful Area Radar feature that helps users explore surroundings of rental properties!

**Quick Start:**
1. Add your Mapbox token to `.env`: `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN=your_token_here`
2. Navigate to `/radar` in your browser
3. Select filter chips to discover nearby amenities
4. Click "Analyze Area" for AI insights
